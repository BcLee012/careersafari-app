# CareerSafari · Demo（用户画像端 + 职场端沉淀）

面向**大学初期人群（大一 / 研一 · 方向未定型）**的职业认知与决策支持原型。
本目录只做两件事：**定义求职需求** 与 **沉淀岗位证据**。

## 快速开始

```bash
./run.sh
# 打开 http://127.0.0.1:8765/
```

依赖由 `run.sh` 自动用 `uv` 创建 `.venv` 安装；也可手动
`uv venv --python 3.12 .venv && uv pip install --python .venv/bin/python -r requirements.txt`。

### 配置 `app/.env`

| 键 | 说明 |
|---|---|
| `STEPFUN_API_KEY` | Stepfun API key（OpenAI 兼容协议）。未配置时 LLM 功能走 **mock 降级**，不假装分析成功 |
| `STEPFUN_BASE_URL` | 默认 `https://api.stepfun.com/v1` |
| `STEPFUN_MODEL` | 默认 `step-1-8k` |
| `ADMIN_TOKEN` | 写操作令牌。**未配置时写操作直接关闭（fail closed）**；首次启动会自动生成并写入 `.env` |
| `FETCH_ALLOW_NON_PUBLIC` | `1` = 关闭 SSRF 公网地址校验。**仅本地开发用**（透明代理环境会把全部域名解析到 198.18.x.x 导致误杀）。公网部署必须关闭 |
| `FETCH_ALLOWED_SUFFIXES` | 逗号分隔，追加受控采集白名单 |

`.env` 已被根目录 `.gitignore` 排除，不会进入 git。

## 两个页面

**① 用户画像端** —— 采集顺序即设计原则：

1. **硬约束**（专业/年级/地域/时间窗/不可接受项）—— 先问筛子，再问偏好
2. **能力自评两栏** —— 通用可迁移 / 目标岗位相关；每项区分「有证据」与「仅自述」
3. **兴趣** —— RIASEC 为主结构（18 题），MBTI 为可选辅助标签并强制展示信度局限
4. **价值观权重** —— 用于同分方向的排序
5. **显式登记未知项** —— 「我不确定」是合法输出，系统不许猜

输出一张**求职意向定义卡**，每项标注证据等级（user_stated / unverified / unknown）。

**② 职场端 · JD 沉淀** —— 三种入口：手动粘贴 / URL 受控采集 / 文件导入。
LLM 拆解为原子化需求后，**必须经人工确认才入库**。

## 三条核心机制

**1. 原子化判据：拆到「能否被单独验证」为止。**
「熟悉 SQL」不可验证；「能独立编写多表 JOIN 查询」可验证。这个判据决定后端匹配能不能做——
拿不可验证的条目比对用户自评，比出来的数是假的。

**2. 生成后校验（evidence_span 回查）。**
每条需求必须附 `evidence_span`（JD 原文逐字复制的支撑句）。程序把 span 归一化后回到原文做子串匹配，
匹配不上的标记「无原文支撑」并降级为 `team`（团队判断），不当作外部证据采信。
全部不通过则整体拒绝入库。**这是「系统不输出资料库外的事实」的最小可运行实现。**

**3. 数据分层与可回溯。**
`responses`（用户原话，append-only + schema_version）与 `profiles`（解析结论）分离；
`jd_records` 永不修改，`positions` / `requirements` 是其派生视图。
任何时候都能回答「这条结论是基于哪版问卷、哪条原始回答得出的」。

## 安全设计（移植自上一个项目）

- 写操作（`/api/jd/confirm`）要求 `X-Admin-Token`；`ADMIN_TOKEN` 未配置时**直接关闭**，不放行。
- SSRF 防护：协议白名单 + DNS 全 IP 校验 + **逐跳重定向校验**（否则 302 到 169.254.169.254 可绕过首跳）。
- IPv4-mapped IPv6（`::ffff:127.0.0.1`）先拆开再判断。
- 限流：`/api/jd/parse` 10 次/分钟（要发外部请求）。
- URL 采集走域名白名单，**不采集智联 / BOSS / 猎聘**（反爬严格，且批量抓取有合规风险）。

## 已知边界（诚实交代）

- 主流招聘官网是 JS 渲染的 SPA，本地 `requests` 抓不到正文。URL 采集只对
  高校 / 政府 / 企业官网校招页可靠；抓不到时会明确报错并提示改用手动粘贴。
- 未实现匹配算法。本目录只负责**两端数据的定义与沉淀**，匹配是下一步。
- 以个人身份在中国大陆无法合规公开运营招聘信息站（ICP 备案限制 + 《人力资源服务许可证》）。
  本原型定位为「职业认知与决策支持工具」，**不做岗位聚合、不做投递撮合**，本地运行。
- LLM 配额受限时走 mock 降级，界面会明确标注「未做真实分析」。
