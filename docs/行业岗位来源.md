# 金融、制造与物流岗位来源

本轮按用户授权补充企业官方来源，范围为实习与校招。岗位族按职责与产出确定，来源行业不直接决定分类。

|企业集团|官方入口|采集方式|阶段依据|日期依据|
|---|---|---|---|---|
|中金公司|[招聘官网](https://cicc.zhiye.com/)|官方列表、详情、招聘项目标记接口|项目实习类别；“校园招聘/暑期实习”还须用岗位绑定的项目标记区分|详情 PostDate|
|中信证券|[招聘官网](https://careers.citics.com/)|官方前端使用的列表与详情接口|详情 type=校园招聘，限定总部校招通道|响应未提供岗位发布日期，保持未知|
|开源证券|[官方实习列表](https://www.kysec.cn/index.php?m=content&c=index&a=lists&catid=851)|企业官网 HTML，详情申请链接的岗位 ID 与页面 URL 相互核对|详情“实习生招聘”及申请类型|详情“发布时间”|
|国投证券|[企业官网](https://www.sdicsc.com.cn/)、[官方实习入口](https://wecruit.hotjob.cn/SU625d4a0b2f9d24287db127c8/pb/interns.html)|企业官网链接的特定招聘租户，公开列表与详情接口|详情 recruitType 与列表、路径一致|详情 publishFirstDate；publishDate 单独保留为刷新字段|
|美的集团|[校园招聘官网](https://careers.midea.com/)|官方招聘项目、岗位列表及详情接口|岗位与项目 ID、项目类型、雇佣类别共同确认|没有发布日期；岗位编号和毕业时间均不替代发布日期|
|顺丰集团|[校园招聘官网](https://campus.sf-express.com/)|官方岗位列表及详情接口|详情 seasonName 与 seasonType 共同确认|createDate 是创建时间，updateDate 是更新时间，均不填发布日期|

中金、中信证券招聘官网的企业声明确认其招聘身份。国投证券招聘租户通过企业官网的“校园招聘/实习招聘”链接核对，不能把其他企业或招聘服务商计为同一来源。各集团事业部、子公司仍只算一家独立企业。

## 数据如何使用

1. 保留原始 HTML 或接口记录、岗位来源 URL、详情接口及抓取时间。
2. 绑定岗位身份、企业和阶段；缺失或相互冲突的字段不得强行补出。
3. 运行现有 AI 提取、逐项原文支持审查和最多一次修复。失败记录保持隔离。
4. 日期未知的检查通过记录，可以浏览职责与要求，不能进入“近期有效 JD”计数或正式岗位族匹配。
5. 正式可比对门槛仍是最近 24 个月内至少 6 份去重 JD、3 家独立企业，共同能力至少由 2 家企业支持。

原文、通过数量与覆盖门槛分别统计。官方发布能确认招聘文本出处，AI 审查能检查提取是否有原文支持，两者均不能证明日常工作已获员工核实或样本具有行业代表性。

## 自动采集与续跑

采集入口为 `app/collect_sectors.py`。可限定企业、先采集原文，再限定数量自动检查；已经检查或待确认的来源不会在普通续跑中反复调用模型。发现关键词仅负责候选排队，最终分类由完整职责决定。后续队列已排除与首批学生无关的材料研发、健康研究和博士后等标题；首批已通过的一条博士后记录仍待范围处理，不能把队列调整当作旧记录已修复。

本轮快照保存在本机 `app/data/evidence/2026-10-11-sector-expansion/`，属于忽略目录；数据库修改前已有独立备份。统计与缺口见 [本轮记录](evaluations/2026-10-11-sector-sources/report.md)。

## 仍需补充

- 金融来源目前以证券机构为主，后续需增加银行、基金等不同雇主类型。
- 美的、顺丰已提供供应链计划、采购、仓储物流和网络规划的实际岗位文本，但首次发布时间缺失，仍需其他明确标注发布日期的制造、零售及物流企业。
- 广发证券官方入口已定位，本机采集遇到连接错误；中芯国际详情目前仅显示更新时间。本轮未将二者计算为已接入来源。
- 真实学生或职场人员的分类与推荐质量评估仍待开展。
