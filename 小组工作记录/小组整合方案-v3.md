# CareerSafari 小组整合方案 v3

> 基于 lx、tmj、xrr、lsy、Bruce 五份方案合并，并经第一性原理重审修正。供小组线上讨论定稿。

## 0. 一页结论

**五位成员独立收敛到同一判断**：市场的断裂点不在「缺岗位信息、缺工具」，而在**决策与路径**。

v3 的核心修正是：**把我们「以为的优势」换成「能证明的优势」**。

| | v2（重审前） | v3（重审后） |
|---|---|---|
| 产品入口 | 目标反推型（用户输入目标岗位） | **方向发现驱动**（用户无需自带目标；目标是系统输出之一） |
| 错位论证 | 平台没动力做深 + 早期节点竞品少 | **仅保留「需求侧覆盖全周期 + 供给侧早期稀薄」两个事实**；不再声称对手行为，不再把竞品少当机会 |
| 全周期 | 产品定位（陪伴四年） | **叙事层**（对投资人/学生处）；产品承诺 = 单节点做深 + 节点间可迁移 |
| 可验证性 | 统一称护城河 | 拆为**产品层**（依据可点开、分级标注）+ **工程层**（评估 CI，是我们的可信度） |
| L2 依据 | 每步挂依据 | **依据分级**：可溯源 / 团队判断（带置信度） |
| Demo 用户 | 大二学生小A | **大三上学生（面临实习申请，有真实 deadline）** |
| 分工 | 按角色名 | 按**唯一交付物**；消除单人单点 |
| Done 标准 | 核心链路跑通 | **非组员真实用户走完 10 分钟并能说出「我要验证什么、下周做什么」** |
| 商业模式 | B2B2C 为路径 | **标注为未验证假设** + 本周补 2-3 位就业中心老师访谈 |

## 2. 产品定义

### 2.1 定位修正：从「目标反推」到「方向发现驱动」

**重审发现的问题**：我们的核心证据是 77.1% 的大学生没有明确职业规划、最大困难是「不清楚自身适配方向」——**这个用户的定义性症状就是「没有目标」**。而「目标反推型」入口要求用户输入目标岗位，等于要求用户提供他们唯一没有的东西。

**修正后的产品逻辑**：

```
用户不知道能干嘛（不需要自带目标）
      ↓
系统基于 专业 + 课程/技能现状 + 市场数据 → 给出 2-3 个有依据的候选方向
      ↓
用户选择（或否定）一个方向  ← 「目标」在此产生，是系统的输出而非输入前提
      ↓
反推引擎启动：差距分析 → 分学期路径 → 依据挂载
      ↓
复盘 → 可更换方向重新生成
```

「目标反推」从**入口**降级为**引擎**。附带好处：品牌名 **CareerSafari（探索）** 与这一定位天然一致。

### 2.2 节点序列（作为 roadmap 与分工框架）

产品按关键节点组织内容。每个节点有统一结构：触发条件 → 核心决策 → 节点引擎（tmj 七步闭环）→ 节点资源 → 复盘输出。

| 节点 | 时点 | 核心决策 | 计划 |
|---|---|---|---|
| 高考报志愿 | 高三暑假 | 选什么专业/学校 | 叙事前端，不做 |
| 专业认知与分流 | 大一 | 是否转专业 | v2 候选 |
| **方向探索** | **大三上（暑期实习前）** | **往哪个方向走、差什么、怎么补** | **Demo 聚焦** |
| 实习与深化 | 大三下-大四上 | 投什么实习、补什么证据 | v2 候选 |
| 求职冲刺 | 大四 | 投什么岗位、Offer 怎么选 | 红海，明确不做 |
| 入职后调整 | 毕业后 | 试用期、首次转型 | v3+ |

**如实定位**：节点结构是**内容组织方式**，不是技术架构（每个节点跑同一套引擎）。它的真实价值是：①v2 扩展路径可读（横向扩节点而非堆功能）②内容生产可按节点分工。**不拔高为护城河。**

### 2.3 错位论证的诚实版本

**保留的（有证据）**：
- 需求侧客观覆盖全周期（tmj 调研：从入学选方向到入职调整每个环节都需要规划支持）
- 供给侧在早期节点稀薄（竞品研究报告盲区 4：产品只覆盖求职窗口期约 3 个月）

**不再声称的（无证据或已被反例）**：
- ❌「平台没动力做深」——职悟空上「职业生涯长期记忆系统」说明智联在做四年留存，不是只做交易撮合
- ❌「早期节点竞品少 = 机会」——空房间谬误：竞品少同样可能因为需求弱

**自认的风险（写进报告）**：早期节点需求强度未经一手验证；我们自己的前期分析就指出过大一阶段的迷茫是低烈度的。**因此 demo 节点选在「大三上、暑期实习前」——有真实 deadline 驱动的方向决策，痛点强度显著高于大一。**

### 2.4 定位语

> 「不是替你决定职业，而是让每个职业选择都有证据、有下一步、有验证方法。」（取 lx）

## 3. Demo 范围（9/28，约 6 天）

### 3.1 用户故事（v3 修正：痛点更强的时点）

> 大三上学生小A，暑假要投实习，但说不清自己该投供应链、运营还是数据分析，也不知道现在开始补什么来得及
> → 系统基于其专业/课程/技能现状，给出 3 个候选方向，每个附匹配依据与差距概览
> → 小A 选「数据分析师」→ 展示该方向真实岗位要求与个人差距（已有/待补/待验证）
> → 生成分学期准备路径，每步挂依据（可溯源/团队判断分级标注）
> → 标注最大未知项（「是否享受与数据独处」），给出一个两周迷你项目作为低成本验证任务

### 3.2 功能清单

| # | 功能 | 对应引擎步骤 | 来源 | 优先级 |
|---|---|---|---|---|
| 1 | 现状采集（6-8 问：专业/年级/课程/技能/兴趣/约束） | 认识自己 | tmj 2.3.1 | **必做** |
| 2 | **方向推荐 3 个（附匹配依据）** | 形成选择 | lx ② / tmj 2.3.2 | **必做（入口）** |
| 3 | 证据与置信标注（事实/推断/未知） | 信任保障 | lx ④ / tmj 2.3.8 | **必做** |
| 4 | **依据分级（可溯源 / 团队判断+置信度）** | 信任保障 | 第一性原理重审修正 | **必做** |
| 5 | 差距分析（已有/待补/待验证） | 规划路径 | lx ⑤ / lsy 匹配层 | **必做** |
| 6 | 分学期路径生成 | 规划路径 | lx ⑥⑦ / tmj 2.3.4-5 | **必做** |
| 7 | 换方向重生成 | 复盘调整 | tmj 2.3.7 | 演示用 |
| 8 | 方向同标准比较 | 形成选择 | lx ③ | 有余力 |
| 9 | 低成本验证任务 | 验证方向 | tmj 2.3.3 / xrr 微体验 | 有余力 |

**明确不做**：简历上传解析、AI 面试、社区、学校后台、长期记忆、完整测评、大规模爬虫、其他节点。

### 3.3 数据方案

- **10-20 个精选岗位画像**，字段取 lsy 职业知识体系：职业名称 → 工作任务 → 核心技能 → 使用工具 → 发展路径 + 薪资区间 + 应届进入方式 + 常见专业来源
- 每个画像挂 **1-3 条真实 JD 引用**（公开可溯源）
- **L2 内容分级生产**：能溯源到培养方案课程号/证书考试大纲的标「可溯源」；属于团队教学判断的标「团队判断 + 置信度」——宁可少挂，不可挂假
- 第 6 位在职成员提供 1-2 个本行业岗位画像及其真实路径案例
- 不做爬虫、不建三层图（入 v2）

## 4. 实现路径

```
用户输入（6-8 问，节点=大三上方向探索）
      ↓
预置岗位画像库（10-20 个，含 JD 引用）
      ↓
LLM（DeepSeek / Kimi / Stepfun）→ 3 个候选方向 + 匹配解释
      ↓
用户选择 → LLM 生成差距分析（已有/待补/待验证）+ 分学期路径
      ↓
程序层：依据挂载（关联画像字段 + JD 链接）+ 三色标注 + 依据分级
      ↓
Streamlit 展示 + 演示「换方向重生成」
```

- **技术栈**：Python + LLM API + Streamlit，全本地运行
- **工程原则**（取 xrr）：AI 不自由创造事实——岗位要求来自预置画像，LLM 只负责解释与组合；每条输出可回溯到画像字段
- **评估分两层（v3 修正，不再混称护城河）**：
  - **产品层**：依据可点开 + 三色标注 + 依据分级 → 直接给用户的可信度
  - **工程层**：demo 版 = 3 人交叉走查 10 条输出；完整评估 CI 五项核查入 v2 → 这是我们的可信度，不是学生付费点

## 7. 商业模式与风险（v3：标注未验证）

### 7.1 商业模式（假设，非计划）

- **B2B2C（学生处/教务 + 家长）**：标注为**未验证假设**。竞品报告中「B2B2C 是唯一被验证路径」是对 Huntr、Leland 等**有销售能力的公司**成立，对我们不成立；且国家平台「智慧小业」免费且政策推动，高校预算竞争现实更复杂
- **本周验证动作**：lx 访谈 2-3 位高校就业指导中心老师/辅导员，问三件事——现在用什么工具、最缺什么、愿不愿意试用学生做的原型。这一个动作的商业信息量超过整章推理
- **Freemium**：产品内试探个人付费意愿，不作收入主论证

### 7.2 风险与责任边界

| 风险 | 应对 |
|---|---|
| 重大决策责任 | 定位「决策材料提供者」，不替用户决定；建议附依据与备选 |
| 心理危机 | 识别明显危机信号时给转介路径（取 tmj 2.3.8） |
| 谄媚与过早决策背书 | 提示词层面防「为好听而背书」；v2 入评估 CI |
| 数据合规 | 全本地处理；JD 爬取控制频率（v2 才涉及） |
| L2 依据不可溯源 | 分级标注 + 团队判断带置信度，不挂假依据 |
