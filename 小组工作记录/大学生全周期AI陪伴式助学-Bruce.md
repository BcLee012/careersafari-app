# 大学生全生命周期 AI 陪伴式助学 · 产品方案

**成员**：Bruce ｜ **日期**：2026-09-22 ｜ **类型**：定位与架构提案

## 一、原始陈述

> 「一个可行的方案是，大学生全生命周期的 AI 陪伴式助学，这里面包含每个关键节点的资源梳理和建议，可以在大一，甚至在高考报志愿的时候就可以进行规划，因为后期在大学生求职节点的产品已经很多了。」

## 二、核心判断

**市场不缺求职工具，缺的是「更早、更长」的规划支持。**

现有 AI 职业产品的火力高度集中在**求职窗口期**（简历、投递、面试、Offer）——智联职悟空、各类 AI 简历/面试工具皆如此。而学生真正困难的决策大量发生在那之前：选什么专业、要不要转专业、往哪个职业方向走、现在该补什么。**越早的节点，产品越少；越早的节点，决策权重越高。**

因此本方案的定位是：**把职业规划从「求职前 3 个月的工具」提前为「贯穿大学四年的陪伴」，并按关键节点组织供给。**

## 三、为什么是全周期（证据）

| 证据 | 来源 | 说明 |
|---|---|---|
| 需求本身覆盖全周期：从入学选方向、实习试错、求职冲刺到 Offer 选择与入职调整，每个环节都需要规划支持 | tmj 调研 | 全周期不是产品设计上的一厢情愿，是需求侧的客观特征 |
| 仅 **22.9%** 的大学生有明确职业规划，**77.1%** 存在职业认知滞后 | 中国青少年研究中心（引自 tmj） | 迷茫是多数人的默认状态，且从入学就开始 |
| 未拿到 Offer 的毕业生中 **36.2%** 归因于「过度迷茫，不清楚自身适配方向」，连续多年居首位 | 智联招聘《2024 大学生就业力调研报告》（引自 tmj） | 求职端的失败，根源在更早的方向未定 |
| **64.8%** 的大学生表示不清楚市场情况 | 中国青年报社社会调查中心（引自 tmj） | 信息缺口贯穿全程，不是求职前才出现 |
| 现有产品「只覆盖求职窗口期，不覆盖职业全周期」 | 竞品研究报告（盲区 4） | 供给侧的结构性空白，直接印证错位空间 |

## 四、产品架构：关键节点序列

产品不做成功能列表，而组织成**一条时间轴上的关键节点序列**。每个节点有统一结构：

```
触发条件（年级 / 时间 / 事件）
      ↓
该节点的核心决策（选什么）
      ↓
节点内引擎：认识自己 → 了解职业 → 形成选择 → 验证方向 → 规划路径 → 行动 → 复盘
      ↓
节点资源梳理（该时点可用的校内资源 + 公开资源 + 可执行的下一步）
      ↓
复盘输出（认识变化 + 带往下一节点的问题）
```

| 节点 | 时点 | 核心决策 | 竞品覆盖 |
|---|---|---|---|
| 高考报志愿 | 高三暑假 | 选什么专业/学校 | 少（志愿填报是另一红海） |
| 专业认知与分流 | 大一 | 是否转专业、如何理解本专业 | 极少 |
| **方向探索** | **大二/大三** | **往哪个职业方向走、差什么、怎么补** | **少（建议 Demo 聚焦）** |
| 实习与深化 | 大三 | 投什么实习、补什么证据 | 中 |
| 求职冲刺 | 大四 | 投什么岗位、Offer 怎么选 | **多（红海，明确不做）** |
| 入职后调整 | 毕业后 | 试用期适应、首次转型 | 少 |

**「资源梳理」是本方案的特色层**：每个节点不只给建议，还给该时点**具体可用的资源**——校内课程/项目/竞赛/社团、公开课程、访谈提纲、实习渠道——并与路径中的能力缺口一一对应（这一点与 lsy 的成长规划层、tmj 的规划落地模块天然咬合）。

## 五、与其他成员方案的关系

本提案提供**时间轴与定位**，其余成员提供**节点内部的实现**：

- **lx** 的「职业假设」框架与 10 分钟 demo 闭环 → 节点引擎的工程化实现
- **tmj** 的七步闭环与信任保障 → 节点内部循环与依据标注
- **xrr** 的职业微体验 → 「验证方向」环节的一种形式
- **lsy** 的职业知识体系 → 节点知识库的字段规范

即：**demo = 把一个节点做深；v2 = 横向扩展节点。**

## 六、对 Demo 的建议

- **聚焦单节点**：大二/大三「方向探索」——全周期中痛点最强、数据最可得、最能演示「以终为始」
- **叙事保留全周期**：汇报时用完整节点序列讲「我们从决策最早点介入」，用单节点 demo 证明做得深
- **高考报志愿只进叙事不进 demo**：用户变为高中生+家长、每年仅一次窗口、数据需求完全不同，且志愿填报本身已是红海
