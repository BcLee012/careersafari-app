# CareerSafari · 小组 Demo 项目

面向**大学生**的 AI 职业发展规划助手。

**核心价值**：完成从用户求职需求精准定义到就业市场岗位精准拆解的端到端匹配，提供全生命周期的职业发展规划建议。
**目标**：用8-10周的时间完成MVP，做出一个可展示且具备落地潜力的AI工程产品。

## Demo 合格标准

1. 系统不输出资料库外的事实（证据 ID + 引用约束 + 生成后校验）

## 技术栈

Python 3.12 + FastAPI + SQLite + 原生前端（单页两 tab），LLM 走 Stepfun（OpenAI 兼容协议），全部本地运行。

> 原定的 Streamlit 已改为 FastAPI + 单页前端：需要 SSRF 防护、逐跳重定向校验、
> fail-closed 写操作和后台采集任务，这些 Streamlit 给不了。API 层独立，
> 将来若要换前端只需重写 `app/static/`。
