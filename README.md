# CareerSafari · 小组 Demo 项目

面向**大三、暑期实习前、尚未定方向**的学生的 AI 方向决策助手。

**核心价值**：每条建议都有依据、能点开核查，不确定的明确说不确定。
**Demo 目标（9/28）**：不是演示得漂亮，是让每位组员都能自己判断这个方案可不可行。

---

## Demo 合格标准

1. 系统不输出资料库外的事实（证据 ID + 引用约束 + 生成后校验）
2. 一个非组员用户，无需解释即可走完 10 分钟，并说清三件事：我被推荐了什么方向、我还不确定什么、接下来两周做什么

## 协作约定

- **代码**：本仓库，D2 起技术块两人同步（每天固定一次 push）
- **进度**：`任务看板.md`（仓库内唯一真相源）——成员在群里同步进度与阻塞，Bruce 更新后 push
- **决策**：重要结论写回 `工作副本.md`，避免散在聊天记录里

## 技术栈

Python + LLM API（DeepSeek / Kimi / Stepfun）+ Streamlit，全部本地运行。
