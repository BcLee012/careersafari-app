# CareerSafari

**面向南京大学管理科学与工程专业研一学生的职业探索产品原型。** 帮助学生梳理个人经历与能力证据，了解实习和校招岗位的真实要求，再看哪些方向值得探索、哪些信息还需要补充。

> 当前版本：**0.3 · 岗位证据与匹配原型**。产品仍在验证阶段，不是招聘、投递或录用预测平台。

## 当前进度

截至 2026-10-11，累计整理 **906 个企业官方岗位来源 URL**，覆盖 10 家企业集团；这里的 URL 数不等同于有效去重 JD 数。28 个「岗位族 × 实习/校招」单元中，**7 个达到当前多企业证据门槛**。15 名学生、两周的真实试点尚未开始，推荐效果和付费意愿尚未验证。

最新数字、待补岗位和续接记录见[项目进展与续接](docs/项目进展与续接.md)，行业来源明细见[金融、制造与物流岗位来源](docs/行业岗位来源.md)。

## 产品做什么

1. 学生提供专业、年级、求职阶段、兴趣、能力、课程与实践经历；缺失信息保留为未知，不由系统猜测。
2. 系统按岗位职责和产出整理岗位，保留原始来源、发布日期与原文引用。
3. 系统把个人经历与多个企业共同支持的岗位要求进行比较，给出可探索方向、证据依据、待确认条件和补充信息建议。

当前先服务培养方案对应的五个方向：金融服务与金融工程、复杂工程与智能管理、大数据分析与决策、运营与供应链管理、智能系统管理。只处理实习与校招，不考虑社招。岗位库用于职业探索，不承诺岗位仍在招聘，也不提供投递撮合。

长期陪伴、打卡和动态发展建议留待后续阶段；本阶段重点是把个人画像与岗位信息匹配做好。

## 岗位证据与匹配

岗位来源经过身份、企业、阶段和发布日期绑定，再由 AI 提取职责、要求及岗位分类。程序核对原文引用，第二次 AI 检查每项结论是否受原文支持；存在问题时最多自动修正一次，仍无法通过则进入待确认状态。后续续跑会跳过已经检查的来源，减少重复工作。

正式比较门槛为每个岗位族、每个招聘阶段至少有 **6 份近 24 个月有效去重 JD、3 家独立企业**，且共同能力至少由 2 家企业支持。没有明确发布日期的岗位不能计入近期门槛。满足门槛只代表证据达到当前运营规则，不代表行业全面覆盖。

匹配使用可解释的内容与证据规则。MBTI 是可选的自我探索信息，不参与筛选或排名；软实力与专业能力分开记录；用户未填写不算能力缺口。当前权重是待校准的工程参数，系统不输出录用概率。

## AI 工程与 O*NET

- **岗位处理：**来源快照、结构化提取、引用回查、语义复核、单次修复、失败隔离及可续跑的检查缓存。
- **岗位匹配：**程序执行阶段与资格判断、跨企业能力证据汇总和排序，LLM 不直接决定匹配结果。
- **职业知识检索：**使用 O*NET 31.0 建立带引用的 RAG。当前为 FTS5/BM25 词法检索和受控中英词扩展，尚未加入向量检索。
- **边界：**O*NET 来自美国职业分类，只作为职业知识参考；不能替代国内岗位证据、学历要求或个人能力验证。

O*NET 原始文件需要首次下载并生成本地索引，详见[岗位覆盖与匹配方法](docs/岗位覆盖与匹配方法.md)。大型原始岗位快照和 O*NET 文件保存在本地忽略目录，不随仓库克隆。

## 本地运行

需要 macOS/Linux、Git 和 `uv`。`run.sh` 会用 `uv` 创建 Python 3.12 环境并安装依赖。

```bash
git clone https://github.com/BcLee012/careersafari-app.git
cd careersafari-app/app
cp .env.example .env
# 在 .env 中设置 STEPFUN_API_KEY，供岗位 AI 提取、语义复核及未缓存的 RAG 问答使用
./run.sh
```

启动后打开 <http://127.0.0.1:8765/>。用户画像和确定性匹配可在没有模型密钥时浏览；AI 岗位检查及未缓存的职业知识问答需要配置可用的 Stepfun 密钥。仅在可信的本机环境运行，不要把管理端口直接暴露到公网。

O*NET 首次导入（可选，需网络）：

```bash
cd app
.venv/bin/python import_onet.py
```

数据库升级会保留已有记录。岗位原始快照、O*NET 表格与缓存位于 `app/data/evidence/` 和 `app/data/onet/`，不会随仓库自动下载或同步。

## 项目结构

|路径|用途|
|---|---|
|`app/careersafari/profile.py`、`schema.py`|问卷、个人画像与数据结构|
|`app/careersafari/ingestion.py`、`extractor.py`|岗位提取、原文引用检查和 AI 语义复核|
|`app/careersafari/match.py`、`ranking.py`、`families.py`|能力证据比较、排序和受控岗位族|
|`app/careersafari/coverage.py`、`onet.py`、`rag.py`|岗位覆盖门槛、O*NET 数据检索及引用问答|
|`app/collect_evidence.py`、`collect_sectors.py`|可续跑的企业来源采集器|
|`app/static/`|本地网页界面|
|`docs/项目进展与续接.md`|已确认范围、当前进度、缺口与交接信息|
|`docs/evaluations/`|带时间戳的实际运行记录|

能力词表、培养方案课程映射和候选岗位族由 `app/careersafari/curriculum.py` 维护，并自动生成在下面的参考表中。

## 当前限制

- 7/28 个岗位族与阶段达到证据门槛；金融研究和若干供应链岗位仍需补充不同企业的近期来源。
- 906 个来源 URL 不等于 906 个通过检查的有效 JD；自动检查通过也不等于员工已核实岗位实际工作。
- 个人偏好和匹配参数尚未通过真实学生试点校准；不能据此声称推荐准确率或市场代表性。
- O*NET 当前是词法检索；中文问题覆盖范围受受控词扩展影响。
- 长期陪伴功能和 UI 全面改版尚未完成。
